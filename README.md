# Notes App

A simple and intuitive note-taking application built with JavaScript and HTML.

## Features

- ✏️ Create, edit, and delete notes
- 💾 Persistent storage for your notes
- 🎨 Clean and user-friendly interface
- 📱 Responsive design

## Technologies Used

- **JavaScript** (53.5%) - Application logic and interactivity
- **HTML** (46.5%) - Markup and structure

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge, etc.)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Shadan0786/Notes-App.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Notes-App
   ```

3. Open `index.html` in your web browser to start using the app.

## Usage

- **Create a Note**: Click the "New Note" button and start typing
- **Save a Note**: Your notes are automatically saved
- **Delete a Note**: Click the delete button next to the note you want to remove
- **Edit a Note**: Click on any note to edit its content
